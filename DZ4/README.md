# HW4 — Robot Detection

# Описание

В работе был собран датасет робота из видеозаписи. Видео было нарезано на кадры, после чего изображения были размечены вручную в формате YOLO.

# Данные

- Исходное видео: "videorobot.mp4"
- Количество размеченных изображений: 109
- Класс: "robot"

# Разметка

Разметка выполнялась вручную с помощью LabelImg.
Разбиение датасета

# Датасет был разбит на:

train: 87 изображений
val: 22 изображения

# Обучение

Использовалась модель YOLOv8n.
python train.py

Параметры обучения:
epochs: 30
imgsz: 640
batch: 8

# Результат

После обучения модель успешно детектирует робота на изображениях и видеопотоке.

Основные файлы:
extract_frames.py — нарезка кадров из видео
split_dataset.py — разбиение датасета
train.py — обучение модели
detect.py — проверка модели
